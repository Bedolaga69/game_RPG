# 🗡️ 2D RPG Game in Python

[![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)](https://www.python.org/)
[![Pytest](https://img.shields.io/badge/tested_with-pytest-green.svg)](https://docs.pytest.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Консольная 2D RPG игра, написанная на чистом Python. Проект включает в себя классические механики ролевых игр: выбор классов, управление инвентарем, магазин, процедурную генерацию лута, пошаговые сражения и покрытие кода автоматическими тестами.

---

## 📌 Основные возможности

* **Система классов и персонажей:** Уникальные стартовые характеристики, развитие и классовые особенности.
* **Инвентарь и магазин:** Система покупки, продажи и экипировки оружия и брони, а также генерация случайного лута.
* **Боевая система:** Пошаговые сражения с противниками, расчетом урона, защиты и критических ударов.
* **Модульная архитектура:** Код разделен на логические модули, что упрощает поддержку и добавление нового контента.
* **Модульное тестирование:** Все основные игровые механики и функции покрыты тестами с помощью `pytest`.

---

## 🛠️ Технологический стек

* **Язык программирования:** Python 3.x
* **Тестирование:** Pytest
